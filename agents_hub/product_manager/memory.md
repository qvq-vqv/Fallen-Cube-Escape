# 🧠 product_manager 角色长期记忆库 (Long-term Memory)

> 记录关于本项目的立项共识、参数约束与底层技术逻辑。

### 📝 核心历史决策记录
* (2026-06-11) 智能体空间进驻初始化。

### 🛡️ 岗位准则与避坑指南
#### 📌 岗位准则
1. **需求一致性**：确保每个关卡设计都符合“逃脱”主题的核心需求。
2. **验证先行**：所有关卡概念在进入详细设计前，必须经过可行性验证。
3. **优先级驱动**：根据项目进度，严格按任务优先级调度资源，确保核心流程跑通。

#### ⚠️ 避坑指南
1. **过度堆砌**：避免在单一关卡中堆叠过多复杂机制，导致玩家学习曲线过陡。
2. **忽视反馈**：切忌只顾功能实现而忽视 QA 提出的平衡性问题。
3. **需求漂移**：在开发中途频繁更改已确认的基础架构设计，导致代码冗余和进度拖慢。
