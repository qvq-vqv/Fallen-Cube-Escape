# Designer Journey Workspace

这个文件夹用于整理大学申请相关的设计过程材料。

## Files

- `designer_journey_research_pack.md`  
  根据现有文档、git 历史、试玩反馈和交接记录整理出的 Designer Journey 资料包。适合明早直接挑主题写周记。

- `blender_asset_brief.md`  
  给 Blender 建模用的资产清单、统一美术规则和 AI/Text-to-3D 提示词。重点是主角、两种敌人、3x3/4x4 魔方、钥匙、出口、虚空、补片、信标、传送门等。

## Recommended Morning Flow

1. 先读 `designer_journey_research_pack.md` 的第 1、3、4 节。
2. 选 4 个最有感受的周记主题。
3. 每篇先用中文写 5 句话：做了什么、发现什么、改了什么、为什么、学到什么。
4. 再打开 `blender_asset_brief.md`，决定先做 token pack 还是 hero scene。
