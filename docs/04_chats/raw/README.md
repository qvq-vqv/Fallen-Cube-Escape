# Session Transcripts

Purpose: preserve raw user/assistant design discussion for project memory, handoff safety, and college application evidence.

Rules:

1. Use one file per major phase or version.
2. Keep the user's original wording whenever available.
3. Include date, phase, participating assistants, and reason for the discussion.
4. Do not fake missing old conversations. Mark them as unrecoverable if the thread was compacted or cleared.
5. Keep permanent behavior rules short in `agents_hub/FAIL_SAFE_RULES/GLOBAL_FAIL_SAFE_RULES.md`; store long raw transcripts here or in `docs/04_chats/raw/raw_chat_archives.md`.
