# 黎明魔方 L01-L40 剧情通讯与新手教程步骤对照表

本文件汇总了当前项目中已实装的 40 个关卡的 E-7 剧情通讯脚本（`dialogue.js`）以及关卡内置的交互式新手教程步骤（`levels.js` 中的 `tutorialStepsConfig`）。

> [!NOTE]
> **E-7 对白**：指关卡开始时，右侧手机聊天框中触发的双语对白。
> **交互教程步骤**：指屏幕中下方的悬浮引导控制台，强制要求玩家完成特定交互（如 Look、Zoom、Move、Twist、Tool 等）的步骤。
