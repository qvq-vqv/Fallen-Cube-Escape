# Dimension Hack Design Brief

## 核心定位

这是一款发生在可旋转立方体表面的确定性战术残局游戏。玩家被困在一枚会重组的立方体牢笼上，需要先取得钥匙，再抵达逃生门。敌人的下一步意图公开，玩家通过手动画出路线、消耗整回合旋转立方体层，把看似必死的局面拧成生路。

第一版不追求随机追逃，也不追求传统魔方还原。核心是短小、可读、可复盘的空间残局。

## 一句话卖点

在一枚可旋转的立方体棋盘上，画出逃亡路线，扭转空间，骗过追猎者，拿到钥匙并逃出牢笼。

## 设计铁律

1. 地图必须可信。玩家可以看不出最优解，但不能怀疑格子对应关系。
2. 手动画路是核心快感。默认交互不应是点击终点自动寻路，而是玩家逐格规划路线。
3. 敌人意图公开。游戏应该像下一盘残棋，压力来自有限行动下的解局，而不是隐藏 AI 或随机惩罚。
4. 旋转不是技能按钮，而是世界规则。玩家、敌人、钥匙、逃生门都会随层旋转改变位置。
5. 第一版先做好 3x3。4x4 和随机模式延后，避免增加玩家脑内负担。
6. 右侧 2D 全局展开图是主棋盘，3D 立方体是空间理解和反馈辅助。不能让玩家在两个主视角之间来回承担决策负担。
7. 主线关卡必须是手工残局，不使用随机生成。随机和自由配置只适合后期每日挑战、沙盒或实验模式。
8. 空间想象可以是高级乐趣，但不能是纯粹门槛。当前不把镜头相对方向键列为近期开发重点，因为它会拉高实现复杂度并可能冲淡手动画路核心。优先用可信展开图、合法下一步高亮、悔棋、教程和关卡坡度来照顾普通玩家。
9. 道具和技能必须靠局面价值成立，不能靠规则强制成立。好道具应该像象棋里的马：玩家不是因为系统说“本关必须用马”才用，而是因为不用它，局面会变差、路线会变长、敌人会压近、胜利会消失。

## 核心目标

旧目标“三个数据芯片收集”改为“钥匙 + 逃生门”。

- 逃生门从关卡开始就可见，但未解锁。
- 钥匙从关卡开始就可见。
- 玩家踩到钥匙即可获得钥匙。
- 玩家拿到钥匙后，抵达逃生门即可通关。
- 钥匙和逃生门都必须能被层旋转带走。

这个目标结构让玩家一眼看懂局面：我在哪里，钥匙在哪里，门在哪里，敌人在哪里。

## 核心循环

1. 观察全局展开图和 3D 立方体。
2. 查看敌人的下一步意图和威胁格。
3. 手动画出本回合路线，路线按格吸附并实时验证。
4. 必要时选择旋转某一层，确认行动后观察局面变化。
5. 确认行动。
6. 敌人按公开规则行动。
7. 玩家取得钥匙并逃出，或通过悔棋回退、复盘、重试。

## 地图与交互

右侧地图应改为稳定可信的全局展开图，而不是含糊的局部雷达。

- 六个面固定位置、固定颜色、固定字母。
- 2D 展开图与 3D 立方体双向 hover 高亮。
- 玩家、敌人、钥匙、门在 2D 和 3D 中使用一致图标与颜色。
- 选择旋转层时，高亮该层影响范围。
- 旋转预览不作为第一优先级。更重要的是提供可靠悔棋，让玩家可以试招、观察结果、回退。

### 视觉可读性原则

视觉升级必须先服务读图，再服务质感。当前原型一旦把六个面压成接近同色的深色面板，玩家会立刻失去“我在哪一面、右侧展开图对应哪一块”的信任。这比画面不够高级更致命。

- 六个面必须保留强身份，但颜色不能单独承担空间坐标。每个面必须至少有颜色、字母、纹样/符号三重身份。
- 3D 立方体和 2D 展开图必须共享同一套面身份逻辑，让玩家能从任意视角确认对应关系。
- 每个面的颜色、字母、纹样、格线和 hover/选中反馈要一起工作，避免玩家只靠空间想象或色觉硬猜。
- 色觉可访问性是核心玩法问题，不是设置菜单里的善后选项。橙、黄、蓝、绿等颜色在玩家眼里可能接近时，游戏仍然必须可玩。
- 当前六面纹样：U=上箭/三角，D=菱形，L=条码竖条，R=粗 X，F=靶心圆，B=波纹。3D 面板、2D 展开图和后续教程图鉴都应继承这套语言。
- 可访问性纹样必须少而准。3D 面板可以用大徽章强化身份；2D 展开图只在每个面的中心格显示面徽章，不能把每个格子都铺满纹样，否则会破坏路线、威胁、钥匙和门的阅读层级。
- 逃脱者、追捕者、守钥者不能长期停留在“纯多面体占位”。它们应该像棋子一样有稳定轮廓：逃脱者有方向与生命感，追捕者有尖锐压迫感，守钥者有锁/守门人的权威感。
- 棋子造型要清楚表达功能，但不能堆到遮挡格子。第一原则仍然是：玩家一眼知道谁是谁、站在哪格、下一步威胁什么。
- 任何“更好看”的改动如果削弱面色区分、格子边界或角色识别，都应该回退或重做。

### 灯光与导演原则

当前 3D 魔方很有冲击力，但不能让读图依赖单一方向光。玩家如果必须把某一面对准左上角光源才能看清浅蓝、红色等面，说明画面调度在抢玩法的权力。

- 3D 棋盘接受戏剧性光影，但不接受功能性面板变黑。
- 六个面的基础识别色应接近自发光或稳定底色，不能只靠方向光照亮。
- 光源可以制造边缘质感、体积感和 IP 氛围，但格子边界、面色、棋子位置必须在背光时仍然可读。
- 优先方案是“读图层”和“氛围层”分离：面板颜色、格线、图标使用稳定亮度；空间牢笼、背景、特效再使用戏剧性光影。
- 如果美术追求电影感，暗部只能压背景和非关键信息，不能压玩家当前决策所需的信息。

### 棋子与 IP 方向

棋子不能长期是临时几何体。若想把项目做成自己的 IP，角色符号必须尽早形成可记忆的剪影，但第一版不应直接冲高成本角色建模。

可选方向：

1. 符号棋子方向：逃脱者、追捕者、守钥者都像抽象棋子，有强剪影和图标语言。优点是最清楚、最容易量产皮肤、最适合残局气质；缺点是情感连接较弱。
2. 囚徒与看守方向：逃脱者是小型发光囚徒/潜行者，追捕者是红色猎杀无人机，守钥者是带锁孔的典狱守卫。优点是 IP 感强、容易做海报和剧情；缺点是资产成本上升，且容易遮挡格子。
3. 棋具收藏方向：角色像一套未来棋具，底座统一，上方有职业符号。优点是高级、可持续、适合关卡册和收藏；缺点是如果做得太抽象，会再次回到“只是多面体”。
4. 2D 徽章 + 3D 底座混合方向：格子上站一个 3D 棋座，顶部/正面有永远面向镜头的角色徽章。优点是可读性最强、制作效率高、适合 demo；缺点是纯 3D 沉浸感稍弱。

当前推荐混合路线：短期采用“3D 棋座 + 清晰徽章 + 少量动画”，中期再把最受欢迎的棋子升级成角色化模型。这样既能保住玩法可读性，又能逐步长出 IP 识别度。

### IP Demo 当前标准

我们现在做的就是 IP demo，而不是“玩法做完以后再考虑 IP”。但 IP demo 的第一阶段不应该用大段剧情、复杂技能树或昂贵角色模型来证明自己。那会让项目过早变重，还可能掩盖核心玩法是否真的成立。

当前 demo 必须先证明三件事：

1. 一眼看懂：玩家能在 5 秒内识别自己、钥匙、门、追捕者、守钥者和六个面的位置关系。
2. 一个独特动作：玩家能明确记住“我不是走平面迷宫，我是在可旋转立方体表面画路逃亡”。
3. 一个可记住符号：逃脱者、追捕者、守钥者至少要有清楚剪影和职业感，让玩家截图后仍然能说出“这是谁、它会干什么”。

这三个标准比先写完整世界观更重要。世界观可以逐步长出来，但 demo 如果不能让普通玩家看懂棋盘、记住动作、认出角色，就还不是合格的 IP demo。

短期 IP 表达应该放在：

- 魔方牢笼的第一眼冲击力。
- 逃脱者/追捕者/守钥者的角色符号。
- “取钥即逃、扭转空间”的关卡瞬间。
- 失败与通关弹窗中的少量世界语气。
- 选关界面像一本残局册或逃亡档案，而不是普通配置菜单。

暂缓大剧情的理由不是“不做 IP”，而是 IP 需要先有一个能被玩家复述的核心场面。当前核心场面应是：一个小小逃脱者站在发光立方体牢笼上，画出路线，旋转世界，把追捕者甩到错误的一面。

当前落地决策：

- 3D 魔方应保留更炫酷的受光质感、金属感和霓虹氛围，不能为了可读性直接做成扁平亮色贴片。
- 读图保障应放在更亮的面纹路、格线、边线和基础自发光上：玩家能看清面，但画面仍然有光照层次。
- 当前魔方视觉倾向“暗色面板 + 高亮流动激光线路”：整体面板亮度可以压低，纹路、节点和每格边框要更亮，边框可做错峰流动，像线路在立方体表面运行。
- 流动激光先采用低成本线条 shader：每个外壳块只维护一条边线对象，用 dash offset 在 shader 内形成真实流动，不上粒子、不为每条边创建独立特效。若后续帧率下降，优先降低流动速度/透明度/刷新频率，而不是牺牲棋盘可读性。
- 旋转层高亮优先级高于流动激光。玩家选中层时，该层应稳定变成金色/明确高亮，不能被动态边线效果干扰判断。
- XYZ 轴提示必须是可用工具，不是贴图装饰。它只在旋转关显示，并且要跟随当前选择的 X/Y/Z 轴高亮，承担“旋转轴参考”的职责。
- 颜色区分不足时，不应只调色。第一解决方案是给每个面加可灰度识别的纹样和字母，让橙、黄、蓝、绿在色觉接近时仍然有不同“纹理身份证”。
- 逃脱者、追捕者、守钥者采用统一棋座、角色剪影和镜头徽章。徽章永远面向镜头，确保在旋转和侧面视角下仍能识别。
- 右侧展开图同步使用同一套符号语言：逃脱者是向上逃离符号，追捕者是尖锐捕食符号，守钥者是锁符号。
- 钥匙应该直接像钥匙，逃生门应该直接像出口。钥匙轮廓、门框和逃离箭头是通用读法，但不需要照搬某个现实安全出口标准图标。
- 这不是最终美术，而是 IP demo 的第一层识别系统。后续角色化模型、插画和剧情必须继承这些符号，而不是推倒重来。

路线规划应改为手动画路：

- 鼠标拖拽或逐格点击均可，但路线必须按格吸附。
- 每一段必须是合法相邻格，包括跨面相邻。
- 当路线末端到达任意格子，尤其是边缘或角落时，必须高亮所有合法下一步格子。跨面可走格要被同等清楚地提示，帮助玩家建立空间信任。
- 超过行动点预算的路线变红且不能确认。
- 支持撤销最后一步、清空路线、重新规划。
- 自动最短路可作为提示或辅助功能，但不应成为默认核心交互。

## 手感、特效与音频

手感强化是下一阶段值得做的，但它必须服务“读棋盘”和“确认规则”，不能把精密残局做成吵闹街机。

### 手感目标

- 每次输入都要有明确反馈：可行、不可行、已确认、已撤销、敌人行动、失败原因。
- 反馈应该短、清楚、克制。玩家思考时不能被循环音效或高频闪烁打扰。
- 视觉特效优先解释状态变化，而不是装饰画面。
- 音效优先强化操作确认和危险节奏，而不是长期占据听觉注意力。

### 推荐音效事件表

- 选中格 / hover：极轻的数字滴答，不刺耳。
- 路线吸附到合法格：短促、干净的 `tick`，让玩家感到路线被“锁”进格子。
- 非法路线 / 行动点不足：低频、钝的 `thunk`，不要尖锐报错。
- 执行路线：更厚一点的确认声，像棋子落定。
- 撤销路线末端：轻微反向滑动声。
- 悔棋一步：低音反卷或磁带倒带感，但要短。
- 旋转层：机械摩擦 + 锁定咔哒，音长控制在 0.3 秒左右。
- 钥匙获得：明亮但短的上行音。
- 逃生门解锁：空间打开感，略带低频展开。
- 追击者移动：压迫感脚步或脉冲，音量低于玩家操作声。
- 守钥者引诱：短促警觉音，提示“它被你调动了”。
- 守钥者狂暴：更低、更急的两拍脉冲，明确区分 1 格引诱与 2 格狂暴。
- 失败：快速切断 + 低频坠落，不要长失败音乐。
- 通关：短胜利 stinger，保持克制。

### 推荐视觉特效

- 合法下一步格：轻微呼吸环，不能盖住钥匙、门、敌人和路线。
- 路线绘制：细线逐格点亮，末端有小光点，强化“手绘路线”。
- 跨面移动：在两个相邻面边缘做连续高亮，解决“怎么翻过去”的信任问题。
- 旋转层：被选层轻微抬亮，旋转后有短暂对齐锁定闪光。
- 钥匙获得：钥匙格向玩家格做一次小型粒子收束。
- 门解锁：门边框由锁定色变为逃生色，附带一次开环动画。
- 敌人行动：显示 1-2 格幽灵轨迹，比纯移动更容易复盘。
- 失败捕获：捕获格短暂红色收束，然后弹窗；不要用大幅屏幕震动。

### 背景音乐策略

建议要背景音乐，但不要一开始就上完整主题曲。第一版更适合“低存在感动态氛围”：

- 默认音量低，允许静音。
- 主循环使用冷静、稀疏、可长时间思考的 ambient。
- 敌人接近、守钥者狂暴、钥匙已取得时可以叠加一层轻微紧张音轨。
- 失败和通关用短 stinger，不要让 BGM 中断太戏剧化。
- 浏览器需要用户交互后才能播放音频，所以音频系统应在玩家第一次点击/开始关卡后启动。

如果只做一个音频版本，优先做 SFX + very light ambience。不要先做完整配乐专辑。

当前实现决策：

- 第一版手感强化先用 Web Audio 合成音，不引入外部音频素材，避免授权、体积和加载问题干扰机制验证。
- 先做可静音的低存在感氛围层。若玩家反馈觉得空，再从 ambient 音乐包中挑选或定制。
- SFX 事件比音色品质更重要：先确认哪些行为需要声音，再替换更专业的 Kenney / Sonniss / 自制音效。
- 视觉反馈先做表面光环、短闪、toast 和按钮 pulse，不上重型粒子系统。
- 第一轮艺术强化采用程序化资产：魔方面板纹理、空间牢笼线框、棋子光环、钥匙与门的几何细节。先提升可读质感，不下载大素材包。
- 美术方向应从“赛博调试界面”逐步转成“立方体牢笼里的战术棋局”。科技感可以保留，但必须让玩家觉得自己在操作游戏件，而不是调参数。
- 第一轮美术升级不能把六个面做成同一套深色科技板。面色差异必须比纹理质感更优先，因为它直接决定玩家能不能把 3D 和 2D 对上。
- 逃脱者、追捕者、守钥者应先用程序化棋子轮廓建立识别：逃脱者偏圆、有方向翼；追捕者偏尖、有捕食箭头；守钥者偏重、有锁孔或守门符号。后续再换手绘或建模资产。

### 候选资源

- Kenney UI Audio / Interface Sounds：CC0，适合按钮、路线吸附、确认、撤销等 UI 手感音。
- Kenney Particle Pack：CC0，适合快速做格子高亮、钥匙粒子、门解锁这类轻量 VFX。
- omgaudio：程序化 CC0 音效，可调参数，适合做更独特的科幻提示音。
- Sonniss GDC Game Audio Bundle：高质量、量大、商业可用，适合后期挑选旋转、机械、能量门、冲击类声音；但体量巨大，不适合直接整包塞进项目。
- Mixkit：可快速试听免费音效和音乐，但每类素材需确认对应 license，适合作临时筛选，不作为唯一来源。
- itch.io CC0 Music / Ambient packs：可找临时背景氛围；每个包必须单独确认授权。
- Orbit 这类分层 ambient 包值得参考：基础层 + 危险层 + 对抗层，比单一循环更适合残局压力。

## 空间辅助策略

家长反馈说明当前原型对空间想象弱的普通玩家不够友好。这不是小问题：如果玩家的主要失败原因是“看不懂下一格在哪里”，他们不会进入真正有趣的残局推理。

但当前阶段不建议开发镜头相对方向键。原因是它会把实现重点拉向输入映射和视角歧义，且容易把“手动画路的残局感”稀释成普通移动操作。这个方向可以保留为后期可访问性实验，但不应成为下一版本主线。

当前优先方案：

- 可信展开图：右侧 2D 全局展开图必须成为玩家信任的主棋盘。
- 合法下一步高亮：路线末端周围所有可走格，包括跨面格，都要清楚显示。
- 跨面连续提示：边缘移动时同时在两个面上做连续高亮，让玩家知道“从这里翻到那里”。
- 强悔棋：玩家可以试招、观察、回退，空间理解通过复盘建立。
- 更缓的新手关：前几关不急着放复杂敌人，先让玩家相信格子、钥匙、门和旋转规则。
- 规则图鉴：用静态小图解释六面展开、跨面相邻、旋转层影响范围。

设计底线：

- 降低的是读图门槛，不是谜题判断难度。
- 玩家可以少怀疑“这一格到底接到哪里”，但仍然要想“该不该引诱、什么时候取钥、要不要旋转”。
- 不要为了包容性马上增加新输入模式。先把现有核心交互磨到可信、清楚、少噪音。

## 悔棋与复盘

悔棋是核心系统，不是可有可无的便利功能。它比强行展示所有旋转后残影更符合残局游戏的推演感。

- 玩家应该可以回退到上一个玩家行动前，至少支持一步悔棋。
- 最理想是行动历史栈：移动、旋转、敌人行动、拿钥匙、开门状态都能完整回退。
- 悔棋不应默认惩罚玩家。主线目标是让玩家学会推演，而不是惩罚试错。
- 高阶挑战可以有“无悔棋通关”徽章，但不能影响普通通关。
- 失败后界面应提供“悔棋一步”和“重试本关”，而不是只给重新开始。
- 旋转预览可以简化为“影响层高亮 + 悔棋兜底”。如果后续测试发现玩家仍然迷茫，再补旋转后残影。

## 初始界面与选关

当前原型直接进入配置面板，不足以支撑“残局游戏”的正式体验。需要补出清晰的初始 UI 和选关界面。

- 初始界面不应是营销落地页，而应快速进入实际游戏：继续、选关、设置、规则图鉴。
- 选关界面应像残局册或关卡棋谱，突出每关的核心概念、最佳回合、最佳旋转、是否完成挑战。
- 前几关必须是手工教学残局，不开放复杂 AI 配置，避免玩家在还没学会读棋盘前自己制造坏局。
- AI 自由配置应放到沙盒或实验模式，不能作为主线默认入口。
- 每关开始前可以显示极短谜面：目标、敌人规则、是否引入旋转。
- 选关结构建议做成章节式残局册：读图与画路、钥匙与门、追击者、旋转目标、守钥者。

## 行动资源

第一版使用行动点约束旋转，不再使用额外旋转次数资源。

- 每回合玩家可移动 2 格。
- 旋转 1 层消耗 2 AP，也就是一个完整玩家行动。
- 已引入旋转的关卡可以反复旋转，只要玩家愿意承担回合与敌人行动压力。
- 前几关仍可隐藏旋转控件，这属于教学节奏，不是次数资源。
- 删除旋转次数限制的理由：顺/逆时针判断容易误触，额外限制会让玩家不敢试招，和“悔棋推演残局”的核心相冲突。
- 每关通关评价可以统计回合数、移动步数、旋转次数。

## 敌人设计

敌人应像棋子一样规则清晰、意图公开。

### 追击者

早期唯一敌人。每回合沿最短路逼近玩家，用来教玩家读威胁和路线。

### 守钥者

第三种怪物，作为钥匙附近的局面锁。

- 前期关卡可以没有守钥者。
- 守钥者不能直接站在钥匙上作为默认布局。它必须守“钥匙周边的路”而不是占用钥匙本体，否则玩家会感觉规则在耍赖。
- 守钥者与钥匙至少要留出一个可被玩家理解和利用的解法空隙，例如邻格封锁、巡逻半径、视野威胁或旋转可拆位。
- 后续关卡中，玩家拿到钥匙后守钥者可以进入追击或封门状态。
- 守钥者必须可被引诱：钥匙未被拿走时，如果逃脱者进入钥匙所在面，守钥者改为追主角，但每回合只走 1 格。否则它守钥匙周边，不直接占钥匙。
- “狂暴”定义为公开状态切换：玩家拿到钥匙后，守钥者从 1 格引诱追击变成 2 格追击。它不瞬移、不隐藏规则，但移动速度提升必须清楚展示，让玩家立刻知道“现在该逃了”。
- 拿钥匙后默认不让守钥者守门。守门会把“撤离压力”升级成“门口封锁”，在 3x3 上很容易过难；它可以作为后期高阶关卡或特殊守门者机制，而不是主线默认规则。
- 守钥者的价值不是杀玩家，而是迫使玩家用旋转改变钥匙、怪物、门和自己的相对位置。

## 已确认实现决策

- 主线关卡开局必须可解，并且教学目标必须成立。玩家可以因为自己的走法进入死局，但这时应该依靠悔棋复盘，而不是让初始局面本身不公平。
- 敌人可以经过逃生门，逃生门不是墙；但敌人不应该占住钥匙格，尤其守钥者不能直接站在钥匙上。
- 守钥者首次登场就应该可被引诱：玩家进入钥匙面时它 1 格追击，玩家离开钥匙面时它回到守钥逻辑。后续关卡在玩家拿到钥匙后进入 2 格“狂暴追击”状态。
- 守钥者拿钥匙后不默认守门。守门会显著增加难度和读图压力，适合之后作为独立教学概念，而不是和狂暴追击同时塞进第 8 关。
- 3x3 关卡中，如果拿钥匙会触发守钥者狂暴，钥匙不应放在面中心。中心钥匙会强迫玩家花掉一个完整行动节奏来“缴税”，拿到钥匙时反而站在最难撤离的位置，玩家会觉得题面在耍赖。
- “取钥即逃”类关卡不能靠开局空过来成立。最佳解至少要符合玩家动线直觉：先拆位，再把边缘钥匙吃进逃跑路线上，然后立刻撤离。
- 早期追击者教学也不应要求开局空过。前几关应该让玩家通过移动理解威胁，而不是先学会按“跳过回合”。
- “逃生门不随魔方转动”可以作为后期特殊机关，但不应该作为当前第 8 关的修补方案。默认世界规则仍然是：玩家、敌人、钥匙、门都会随层旋转移动；教学关要通过摆位解决节奏问题，而不是增加例外。
- 失败时游戏必须暂停并弹出结算窗，弹窗要告诉玩家被谁、在哪里抓住，并提供“悔棋一步”。
- 作者验证信息只服务于设计与测试，例如“是否可解”“是否必须旋转”“是否引入狂暴”，不应该暴露给玩家，避免把游戏变成调试器。
- 主题后续要统一为“立方体牢笼/逃亡残局”，逐步减少过多赛博调试味文案。当前原型可以保留技术感，但不要让玩家误以为这是系统配置工具。
- 镜头相对方向键暂缓开发。它可以作为后期可访问性实验，但下一阶段不应让它占用核心 demo 打磨时间。
- 当前照顾空间想象弱玩家的方式，是更可信的展开图、更清楚的合法下一步高亮、更缓的教程关和强悔棋，而不是新增一套输入模式。
- 入口第一屏必须让玩家同时看到残局册、本局谜面、规则速览和进入按钮。固定开始按钮可以保留，但不能压住规则速览；如果 720p 视口需要滚动才知道怎么玩，就是新手 UI 失败。
- 规则速览优先用图标短语，不用长说明：画线走路、钥匙到出口、红格会到、旋转整层。它们是玩家进入第一关前的最低心智准备。
- 第 8 关当前只教“拿钥匙后守钥者 2 格狂暴追击”，不再同时教旋转。最佳解应允许玩家第一回合取钥，让失败原因集中在撤离压力，而不是绕路、误转或额外追击者。
- 3D 镜头必须给边角棋子留安全边界。棋子可以有 IP 造型和体积感，但不能被画布裁掉，也不能看起来像站出棋盘；否则玩家会怀疑格子对应关系。

### 伏击者

暂缓强化。原先“预测玩家上一动”的逻辑可能增加不透明感。若保留，应改成公开、可读、像棋子一样的规则，例如封锁路径终点或沿固定方向巡逻。

## 关卡教学曲线

每一关只引入一个新概念。

0. 新手读图关：不放敌人，不放旋转，只教展开图、合法下一步高亮、跨面移动和撤销路线。
1. 没有敌人，只教手动画路线到门。
2. 钥匙 + 门，没有敌人，教目标顺序。
3. 一个追击者，教敌人意图公开。
4. 第一次旋转门，教门会随层旋转移动。
5. 第一次旋转钥匙，教可以把目标转近。
6. 守钥者登场：进入钥匙面会引诱它 1 格追来，教玩家可以调动守卫。
7. 通过旋转拆开守钥者和钥匙，教“先换相对位置，再取钥”。
8. 暂时不再同时教旋转和狂暴。先关掉旋转，只教“拿钥匙后守钥者进入 2 格狂暴追击”，形成取钥即逃的撤离压力。

## 通关评价

主线只要求通关，避免玩家被三星卡死。评价系统服务于复盘和长期挑战。

- 基础通关：拿钥匙并逃出。
- 最少回合：残局最优解。
- 最少旋转：强调空间理解。
- 可选挑战：不进入威胁格、全程不回头、一次规划完成等。
- 可选挑战可以包含“无悔棋通关”，但不应让普通玩家觉得悔棋是羞耻或扣分。

## 内部试玩问题清单

以下问题来自当前原型的玩家视角试玩，优先级高于新增玩法。

### P0：关卡教学必须真的成立

- 第 6 关“守钥者”必须明确教会引诱：玩家进入钥匙面时它 1 格追击，玩家离开钥匙面时它回到守钥逻辑；关卡必须通过可解性验证，不能靠敌人占钥匙或死封路线制造难度。
- 第 4 关“把门拧近”如果不旋转也能通关，就没有教到旋转门。教学关必须通过布局强制玩家使用该课的核心概念。
- 每个教学关都要有明确验证目标：是否必须画路、是否必须拿钥匙、是否必须读敌人意图、是否必须旋转钥匙/门、是否必须利用悔棋。

### P0：空间想象门槛过高

- 普通玩家可能不是不懂谜题，而是没看懂“下一步会走到哪一面”。这类失败会直接劝退，因为玩家会把它归因于界面不可信。
- 需要先做跨面高亮、下一格预览、规则图鉴和更缓教程，再继续堆更复杂敌人。
- 新手教程必须让玩家先相信右侧展开图和 3D 魔方的对应关系；随后再引入敌人、钥匙、旋转和守钥者。

### P1：入口像残局册，但信息还不够像“棋谱”

- 当前选关卡片只显示标题和章节，玩家不知道这一关会学什么、是否有敌人、是否会引入旋转。
- 第一屏曾在 720p 视口下把规则和开始按钮推到底部。当前已改成紧凑残局册 + 图标规则速览 + 可见进入按钮；后续新增入口信息时必须继续保持“选择关卡 -> 谜面 -> 规则速览 -> 进入残局”完整可见。
- 关卡卡片编号在当前字体下容易看起来像方块符号，应改成更清楚的 `L01` / `1.` 之类格式。

### P1：关内 UI 需要按关卡上下文收起

- 未引入旋转的关卡仍显示完整旋转控件，会让玩家误以为需要学习旋转。
- 没有敌人的关卡仍显示“跳过回合 / AI行动”和“威胁源追踪”，会制造无意义噪音。
- 每关左侧应该突出“本关要做什么”，而不是永远展示全部系统。

### P1：旋转操作仍然是工程语言

- `X/Y/Z 轴`、`第 1 层 (底/左/后)` 对玩家来说仍然像调试工具。需要解释坐标系，而不是把旋转结果全部剧透。
- 更实在的方案是在 3D 背景或画布角落放一个足够醒目的 XYZ 坐标轴，让玩家快速建立“X 是左右、Y 是上下、Z 是前后”的空间锚点。
- 2D 主棋盘可以轻提示本次选择的影响范围，但不要显示太多“谁会去哪里”的完整结果。游戏需要保留一点试招后的突然性，悔棋负责兜底。

### P1：路线提示有效，但还缺解释和层级

- 合法下一步高亮明显提升空间信任，尤其是边角跨面时。但它需要图例或微文案说明，否则玩家可能不知道青色圆环代表“可走下一步”。
- 合法下一步、敌人威胁、路径、钥匙、门同时出现在 2D 图上时，视觉层级容易拥挤。威胁格和可走格需要更明确的优先级。
- 手动画路线还需要“撤销路线最后一步”，不能只依赖整局悔棋。

### P2：悔棋很好，但要强化为复盘体验

- 左侧悔棋和失败弹窗悔棋都存在，但失败原因还不够具体。玩家需要知道“被谁、在哪里、哪一步抓住”。
- 普通悔棋不应只回退状态，还应该让玩家看懂上一手发生了什么。后续可加行动历史：移动、旋转、敌人行动。
- 悔棋按钮可以加快捷键和 tooltip，但不要让玩家觉得悔棋是作弊。
- 失败复盘不能只说“你在敌人攻击范围内所以死了”。那是结果，不是原因。复盘必须解释局面如何收紧：敌人从哪格走到哪格、距离从几格变成几格、钥匙是否触发守钥者 2 格狂暴、旋转是否把双方带到危险相对位置。
- 复盘默认应由玩家主动展开。高手可以选择不看，新手卡住时再打开。
- 语气可以有“最强大脑”或“可爱陪练”皮肤，但只改表达，不降低分析深度。不要写严重 AI 味的抽象句子，例如“落点打开了加速路线”；应改成更像人讲棋的具体话：“钥匙拿到时，守钥者离你只有 1 格；拿钥匙后它一回合能走 2 格。”
- 当前推荐默认语气：聪明、短、带一点陪练感，不毒舌，不卖萌过头。可爱语气可以使用轻量颜文字或软一点的收尾，但不能破坏逃亡残局的压迫感。

### 少字教程层与未来内容模板

少字教程是正确方向，但不能理解成“完全不解释”。本项目的规则比较抽象，尤其涉及展开图、跨面、旋转层、守钥者状态变化。成熟做法是：视觉先讲，文字只补最后 10%。

每个新物品、新技能、新敌人、新世界规则，必须按以下顺序介绍：

1. 先给视觉动作：箭头、目标环、威胁路径、旋转层高亮、感叹贴纸、2 格贴纸、锁图标、幽灵预演。
2. 再给短句命名：每次 4 到 8 个字，最多 12 个字。例如“拖到门”“钥匙→出口”“红格会追上”“旋转整层”“把它引走”“拿钥匙后2格”。
3. 只在第一次出现时强提示。之后保持安静，让玩家自己玩。
4. 如果玩家失败，再给可选残局复盘，解释距离、状态变化和转折点。
5. 不要把长说明塞进关内 HUD。长解释属于文档、图鉴、复盘或设置里的帮助页。

未来新增内容时，必须同时写四件事：

- 视觉符号：玩家不用读字时，看到什么就能猜到规则？
- 短句：一句最短的人话叫什么？
- 第一次登场关：让玩家只学这一件事，不和其他新规则叠加。
- 失败复盘句式：玩家用错后，如何解释“什么时候、在哪里、为什么变危险”？

示例：

- 新物品“传送门”：视觉是 A/B 双端门环同时闪；短句是“进 A，出 B”；首关只放一个传送规则，不放守钥者；失败复盘说明“你出门后落在红色预告路径上”。
- 新技能“冻结一格”：视觉是目标格结冰并停住敌人预告线；短句是“冻住一回合”；首关只让玩家冻一个追击者；失败复盘说明“你冻错了格，真正压近的是另一条路径”。
- 新世界“门不随层转”：视觉是门外框钉在背景网格上，旋转时其他物体动、门不动；短句是“门固定”；首关必须只教这一个例外，不和狂暴守钥者同时出现。

贴脸失败反馈可以有“跳杀”感，但它不是恐怖卖点。目标是让玩家瞬间明白“敌人贴到我脸上了”，表现应短促、清楚、可爱或帅气都可以，不要长时间惊吓、不要抢走残局复盘的地位。

### 漫画叙事与主角声音

剧情建议用短漫画插片推进，而不是在关内 HUD 堆文字。漫画负责建立“我是谁、我为什么要逃、这个立方体牢笼有多荒唐”，关卡负责让玩家亲手解决眼前残局。

叙事视角采用第一人称，但玩法视角保持 2D 展开图 + 3D 立方体。第一人称适合内心吐槽、章节开场、失败/通关短句；不适合把操作改成主角眼睛视角，否则会破坏读图。

主角声音已经确认：

- 嘴硬、怕死但不承认怕死。
- 聪明，有观察力，但会傲娇吐槽。
- 黑色幽默可以有，但不能把逃亡压力讲没。
- 少讲设定，多讲眼前倒霉事。
- 不写空泛预告片句，例如“脚下不是地面”“神秘空间苏醒”。玩家看到的是魔方、钥匙、门、追击者，文案也应该直接承认这些可见事实。

可用语气示例：

- “我醒在一个魔方上。对，魔方。而且它还会转。”
- “门在那边，钥匙在另一面。设计这个监狱的人，精神状态大概很稳定。”
- “我没有慌。我只是非常冷静地发现，出口锁了，钥匙在怪物旁边。”
- “它走了两格。很好，它甚至比我还积极。”

漫画使用原则：

1. 每格只讲一个可见事实：我在哪、门在哪、钥匙在哪、谁在靠近。
2. 每段漫画控制在 3 到 5 格，章节开场可以 1 到 2 格。
3. 漫画不能替代教程。玩家仍然要通过第一关亲手学会画线。
4. 漫画/通讯结尾要把玩家推回关卡行动，例如“你画，我走。先从这条线开始。”
5. 第一幕结尾给钩子：“门开了。坏消息：外面还有一个更大的立方体。”

当前已落地：

- 开局通讯序章覆盖在残局册上方，玩家可用颜文字回应并进入残局册。
- 结尾漫画只在 L12 通关后出现，避免普通教学关被剧情反复打断。
- 序章文案采用第一人称吐槽，不再使用“脚下不是地面”这类空泛句。

### 玩家-主角互动与平板终端

玩家可以和主角互动这个方向成立，而且比单纯“章节漫画”更适合长线 IP。它能把玩家从“解一道题的人”升级成“正在远程救一个活人/嘴硬倒霉蛋的人”。但这条路必须克制，不能把游戏做成泛用好感模拟。

核心判断：

- 右侧 UI 可以整体包装成一台“逃亡终端/平板”，但“展开图”仍然是默认主页和主棋盘。玩家画路线时绝不能被迫先切回地图，也不能因为聊天页遮住局面而忘掉自己站在哪里。
- 平板模块建议为：展开图、通讯、任务、档案。Tab 名称要短；“和主角聊天”可以作为通讯页标题，不适合做成占宽很长的 tab。
- 主角聊天应该拆成两层：常驻小窗和通讯详情页。常驻小窗一直在，显示主角头像/表情包/短气泡/沉默状态；通讯详情页由玩家点击召出，才承载剧情选项、长一点的对话和关系变化。
- 如果暂时没有正式立绘，不要用廉价临时头像硬占位。第一版可以只保留主角通讯位、信号框、状态文本和短气泡；表情包/头像旁吐槽等到有立绘或明确头像风格后再上。
- 通讯推动剧情，但不在拖线中强行弹出。适合出现的节奏是：关卡开始前、通关后、失败后、章节节点，或玩家主动点开。平时主角可以只发表情，不必讲话。
- “好感值”这个词要慎用。它容易把作品拉向恋爱/养成预期，反而稀释“逃亡协作”的独特性。更推荐叫“同步率”“信任”“默契”，或者只在后台记录，不用数字条直接显示。
- 关系成长不应该给硬战斗力。它可以改变主角吐槽、失败复盘语气、可选小漫画、结局分支、外观纪念品；但不能让玩家因为刷对话而降低谜题难度。
- 对话选项必须短、具体、像人话。不要写空泛人格测试，也不要写“系统总结式正确答案”。玩家选的是“现在怎么安抚/激/吐槽这个人”，不是在填心理问卷。

可用对话节奏示例：

1. 常驻小窗闲置时：主角不说话，终端偶尔弹出“盯——”“别看我，看路”“我很冷静，真的”的短状态。没有立绘时不做头像旁表情。
2. 首次失败后，主角说：“刚才那段我们可以假装没发生。”玩家选项可以是“当然没发生”“重来，我看到了”“先骂地板，别骂我”。
3. 第一次拿钥匙后守钥者加速，主角说：“它刚刚是不是突然认真上班了？”玩家选项可以是“它急了”“你也跑快点”“合理，但我不喜欢”。
4. 第一幕结尾，门后还有更大的立方体。主角可以嘴硬：“出口的意思原来是下一层入口。行，挺有礼貌。”玩家选项影响之后她/他对玩家的称呼和吐槽亲密度，而不是直接影响关卡解法。

普通用户视角下的收益：

- 玩家会更容易产生“我在救人”的情绪钩子，而不是只面对抽象棋子。
- 失败时不只是重试，还能得到角色反应和复盘提示，挫败感更容易被消化。
- 右侧平板把展开图、任务、通讯统一成世界内道具，UI 不再只是工具栏，而是 IP 的一部分。
- 常驻通讯位和短状态能让主角“不说话也在场”，降低文字负担，并形成类似直播/通讯窗口的陪伴感；没有立绘时保持留白，不强行做表情包。
- 长线可持续：后续每个新世界/新敌人都可以配一组通讯事件、失败吐槽、章节漫画和档案，不必一开始就制作昂贵长动画。

必须警惕的风险：

- 如果地图被藏进 tab，核心体验会变慢，玩家会觉得 UI 在阻挡思考。
- 如果好感做成数字和刷选项，项目会显得像半成品恋爱系统，且会吸引错误预期。
- 如果主角说太多，空间残局的紧张感会被稀释。她/他可以嘴硬，可以可爱，可以黑色幽默，但不能变成一直讲解规则的旁白机器。
- 如果每次都让主角讲“规则分析”，会非常 AI 味。更好的比例是：表情和短反应占多数，真正解释只在玩家失败、点开帮助或关键新机制出现时出现。

当前推荐落地顺序：

1. 先把右侧视觉包装成平板终端，但默认仍显示展开图。
2. 增加常驻主角通讯位：没有立绘时先空着，只放信号状态和短气泡，默认不挡地图。
3. 增加通讯页原型，只做少量节点：序章后、首次失败、首次拿钥匙、L12 通关后。
4. 增加后台关系状态，不显示数字条，只用语气变化验证效果。
5. 等玩家确认喜欢这种陪伴感后，再扩展档案、章节聊天、分支结局和正式立绘。

当前已落地：

- 右侧 HUD 已包装为逃亡终端，模块为展开图、通讯、任务、档案。
- 展开图仍是默认主页和主棋盘；通讯、任务、档案需要玩家主动点开。
- 主角通讯位保留空白立绘槽，只显示信号状态和短气泡，不使用廉价临时头像。
- 通讯页已改为“每关一个剧情节点 + 关键事件插入节点”。玩家可见回复只使用颜文字，主角负责叙事和吐槽。
- 主角状态会随局面变化：画路线、持有钥匙、旋转、失败、通关都有短反应，避免长篇规则讲解。
- 通讯选项只记录隐藏语气倾向，不显示数字好感，也不改变谜题难度。

### 元游戏叙事调研结论

调研对象包括 OneShot、The Stanley Parable、Doki Doki Literature Club、Inscryption、There Is No Game: Wrong Dimension 和常见颜文字资料。可借鉴的是结构，不是剧情皮肤。

可借鉴点：

- OneShot 的核心吸引力不是“有个可爱角色”，而是玩家在世界内被承认为一个真实存在；玩家与角色之间形成共同承担命运的关系。本项目可以借鉴“外侧的人”这个定位，但不能抄“拯救太阳/神/只有一次机会”。我们的独特定位应是：玩家是能从外部画路和拧空间的逃亡终端操作者。
- The Stanley Parable 的强项是叙事者会回应玩家行为，让玩家觉得“游戏知道我在干什么”。本项目可借鉴行为回应，但不能变成旁白一直调侃玩家。我们的回应者应该是被困者本人，她关心的是活下去，不是展示作者聪明。
- Doki Doki Literature Club 证明“表层可爱 + 深层异常”有效，但也证明这种路线风险很高，容易把期待带到心理恐怖。本项目不应该做突然恐怖转向。可以有黑色幽默和不安，但必须保持战术残局的公平感。
- Inscryption 的启发是：机制、界面、档案、秘密可以服务同一个世界，而不是剧情和玩法分家。本项目的平板终端、展开图、通讯、档案都应该是世界内道具。
- There Is No Game 的启发是：UI 本身可以成为角色和笑点。但本项目不能把“别玩这个游戏”当主轴，因为我们的核心吸引力是救人和解残局，不是反游戏玩笑。
- 颜文字适合玩家回复，因为它短、情绪明确、不会抢主角台词。玩家像在终端另一端发送反应，主角则用较完整的句子娓娓道来。

市场避让：

- 不做 OneShot 式救世童话，不做 DDLC 式伪恋爱恐怖，不做 Stanley 式哲学旁白，不做 Inscryption 式卡牌秘术。
- 本项目应表达为“通讯救援 + 可旋转立方体战术残局”。玩家不是旁观者，不是神，也不是恋爱对象，而是外侧操作者。

### 第一幕通讯剧情线

第一幕主题：她不是棋子。

世界观第一层：

- 主角在一枚可旋转立方体牢房上醒来。
- 终端称她为 E-7，她拒绝承认这个编号。
- 她暂时想不起本名，但确定自己不是物品、不是棋子、不是测试样本。
- 玩家通过逃亡终端与她建立连接，能在展开图上画路线，并能从外部旋转空间。
- 她能看到玩家画出的路线，像现实上浮出的荧光线；她听不到玩家完整说话，只能收到颜文字情绪。

世界观第二层：

- 钥匙、门、敌人和地板不是分开的道具，而是同一个“折叠机”定义出来的规则对象。
- 这个地方不是普通监狱，而是把逃跑当成训练数据的测试场。
- 玩家越会逃，折叠机越会学习；这给第二幕 4x4 扩张提供理由。
- 第一幕结尾，门后不是自由，而是更大的立方体外壳。主角意识到：它需要她活着，因为死掉的样本不能继续训练逃亡模型。

主角性格：

- 嘴硬，怕但不承认怕。
- 不喜欢被编号，不喜欢被玩家当小宠物哄。
- 会傲娇地承认玩家有用，但不轻易说谢谢。
- 会黑色幽默，但不会把危险说没。
- 对“自己是否也是规则对象”有隐约恐惧，这是 IP 长线情绪核心。

通讯节点：

1. 开场：信号接通，她说明自己站在魔方上，终端叫她 E-7，玩家只能用颜文字回复。
2. L01：她第一次看到玩家画出的路线，建立“你画，我走”的协作关系。
3. L02：钥匙和门被解释为权限对象，世界规则开始具体化。
4. L03：红格被解释为敌人下一步位置，强调公平威胁。
5. L04：玩家第一次旋转世界，她意识到玩家不是普通旁观者。
6. L05：钥匙也跟着转，她开始怀疑自己是否也被地板定义。
7. L06-L08：守钥者和狂暴规则让她意识到钥匙是报警器，不是奖励。
8. L09-L11：教学结束，玩家和她第一次像真正搭档一样处理组合残局。
9. L12：门后出现更大立方体，揭示“折叠机”会学习逃亡，开启第二幕。

玩家回复规则：

- 玩家可见按钮只放颜文字，例如：(⊙_⊙)、(｀・ω・´)、(´･ω･`)、(¬‿¬)、(ง •̀_•́)ง、(・_・;)。
- 颜文字对应隐藏语气：稳定、温柔、吐槽。只影响主角称呼、回应口吻和未来可选小段落，不影响解谜强度。
- 玩家不需要读大量选项文本，避免右侧通讯页变成视觉小说菜单。
- 主角可以讲长一点，但每个通讯节点最多 3 到 4 句。她要娓娓道来，不要演讲。

### 第二幕 4x4 设计储备

完整 4x4 第二幕不应该只是把棋盘放大。玩家试玩后的关键反馈是：4x4 本身并不比 3x3 难理解太多，如果它只是“格子更多”，玩起来会和三阶没有本质区别。

第二幕主题：折叠机会学习。

因此 4x4 的真正价值不是制造理解门槛，而是提供更大的战术容量：更多路线空间、更多敌人站位、更适合容纳道具和技能组合。三阶像一盘短残局，四阶应该开始像一个小型工具箱残局。

第二幕设计修正：

- 可读性仍是底线，但不是卖点。玩家不该因为 4x4 才觉得高级，而应该因为“我能用新工具解开更复杂的局面”才觉得进入了第二幕。
- 第二幕每个新系统都必须提供一个明确动词，例如传送、诱饵、扫描、封锁，而不是只增加数值或按钮。
- 新技能必须服务手动画路和立方体旋转，不能把游戏变成传统技能冷却战棋。
- 新工具必须是“局面诱导使用”，不是“规则点名使用”。关卡验证可以检查某工具是否出现在最佳解或必要解中，但对玩家呈现时不能写成“必须使用 X”，而应该通过敌人压力、门钥匙距离、旋转后果和失败复盘，让玩家自然意识到“不用它会亏”。
- 四阶允许关卡更松一点。不要把每一步都压成极限，否则道具没有表达空间，玩家也只会觉得被算法卡住。
- 教学单位是“学习节拍”，不是“整关”。简单公开规则不需要单独占一整关；它可以在一关前半段安全展示，后半段立刻进入真实决策。
- 不要为了每个新技能/新物品都开专门教学关。那会让玩家觉得自己在排队读说明书，而不是在逃亡。只有会改变输入方式、死亡原因、世界铁律或强策略判断的新机制，才配拥有完整教学关。
- 玩家可以选择是否打开系统分析或提示。喜欢自己想的玩家要能关掉辅助，空间感弱的玩家要能靠工具进入游戏。
- 工具模式和画路线模式必须互斥。玩家在放诱饵、扫描、封锁时，拖拽不能同时生成移动路线，否则普通玩家会第一时间怀疑输入系统。

当前已落地：

- L13「外壳醒来」已作为第二幕原型接入选关。它是 4x4 关卡，但不是完整第二章。
- L13 只放一个追击者、钥匙和门，不引入新物品、不引入守钥者。旋转作为 L04 后的常驻工具仍可使用。它暴露了一个重要问题：纯 4x4 不够像第二幕，必须尽快接入第一批道具/技能原型。
- 引擎已支持按关卡设置 `size`，L01-L12 继续是 3x3，L13 之后进入 4x4。
- 关卡验证器已支持可变尺寸，并额外检查第二幕原型必须运行在 4x4 上。
- 坐标钉原型已被砍掉。理由：普通玩家不觉得“记住一个物理格”带来足够价值，且它会和“蓝圈=下一步可走”产生概念竞争。
- L14-L15 改为四阶宽场压力题：L14 是双追击宽场换线，L15 是守钥者 + 追击者进入 4x4。
- L16 已选择“传送门”作为第一批真正工具原型：两个门端互为相邻格，第一关就加入守钥者压力，避免无怪物教学拖慢节奏。
- L17-L18 用传送门 + 追击/旋转压力验证第二幕是否真的开始形成工具链；L18 已加双追击，不再是单追击轻量题。
- 第二章的新物品和新敌人不应长期停留在设计储备。传送门和第一个追击小考稳定后，下一批再考虑诱饵信标。

第二幕第一批原型优先级：

1. 传送门：连接两个门端格，形成公开短捷径。它是第二幕第一个真正工具，因为不用它会实际亏节奏，敌人也能利用它制造反压。
2. 诱饵信标：放在某格，下一次敌人优先向信标靠近一步。它能强化守钥者/追击者的调度乐趣，但难度和验证成本更高。
3. 锚点门：门不随层旋转，固定在外壳上。它适合作为关卡特殊规则，不适合作为第二幕第一个技能，因为它会改变第一幕建立的世界铁律。

### 第二幕：缺面、补片、诱饵

新的 4x4 工具不是为了让按钮更多，而是为了让棋盘出现三阶装不下的残局结构。四阶魔方的价值应是“空间更大，工具更能发挥”，不是把三阶谜题拉长。

已确认机制：

- 缺面/缺角：魔方表面可以出现黑色缺口。缺口不可走，敌人也不可走；它会随层旋转移动。缺口不是美术破损，而是结构规则：它可以堵路、断追击、制造窄门，也可以把玩家逼到必须改变路线。
- 临时补片：玩家可在任意合法缺口上直接点击放置补片。E-7 可以踩上补片并通过，但不能停在补片上；她离开后补片碎裂。追击者和守钥者默认不能踩补片，所以补片既是一次性桥，也是断尾工具。
- 诱饵信标：玩家可在任意合法空格上直接点击放置诱饵。诱饵持续短时间，敌人优先向诱饵靠近；被敌人踩到后消失。它不是“暂停敌人”，而是让玩家主动改写敌人的目标，从而创造取钥或撤离窗口。

设计标准：

- 缺面必须让玩家一眼看出“这里不能走”。不要把缺口画成普通暗色贴图；3D 和展开图都要有同一个破损语言。
- 补片必须有真实价值。好的补片关应该让玩家感觉“我不是因为系统叫我用，而是不用就会绕远、被追上或无法进入关键线”。
- 诱饵必须有真实价值。诱饵不是花哨减压按钮，而是敌人调度工具；它应该改变守钥者/追击者的目标，给玩家创造一拍窗口。
- 补片和诱饵可以比传送门更强，所以出现它们的关卡允许更高敌人压力。强工具配弱局面会显得无聊，强工具配清楚压力才有爽感。
- 工具模式和画路线模式必须互斥。放补片/诱饵时，点击魔方或展开图执行工具；回到画路模式后才规划路线。
- 玩家端不能写“本关必须使用补片/诱饵”。作者内部校验可以检查工具解是否存在、禁用工具后的替代解是否过强，但对玩家呈现要靠局面自然暗示。
- 后续如果新增更强工具，例如冻结、单向传送、交换位置，必须同步提高敌人密度或空间约束，否则工具会变成无意义的炫技。

当前关卡落点：

- L19-L20：先教“洞是棋盘结构，并且会跟着旋转”，不急着给工具。
- L21：补片首次出现，目标是让玩家理解一次性通过和碎裂断尾。
- L22：缺角进入守钥者局面，缺口既限制玩家，也限制敌人。
- L23：诱饵首次出现，用来调走守钥者或追击压力。
- L24：破面小考，应该考缺口、补片、诱饵的组合判断，不再额外塞传送门，避免全家桶噪音。

推荐第二幕开局节奏：

1. L13：进入第二幕。4x4 不是为了降低难度，而是提供更多路线空间、更多容错和更多追击变化。
2. L14：宽场夹击。不能再教“旋转是什么”，而要让玩家感到四阶空间会让追击包抄变宽。
3. L15：宽场遛锁。不能复读 L13，要把守钥者和追击压力带进四阶空间。
4. L16：传送门 + 守钥者。基础传送门第一次登场也要有怪物压力，例如借传送门绕过守钥者正面，不需要先把它遛开。
5. L17：传送门 + 追击，确认玩家能在压力下主动穿门。
6. L18：传送门 + 旋转 + 双追击小考，验证玩家能把已学会的旋转工具带进第二幕，而不是每章重新学一遍。

2026-06-09 节奏修正：

- 上面这组关卡不等于每个点都要做成完整主线教学关。试玩反馈很关键：如果每个新东西都单独开一关，节奏会像“上课”，推进太慢，玩家学了半天没有发挥空间。
- 第二幕 demo 的目标不是把规则一条条讲完，而是让玩家尽快得到“我刚学会这个东西，马上靠它活下来”的满足感。
- L14/L15 可以合并或缩短：如果二者只是重复证明“4x4 也能追击”，其中一关就应该变成可跳过低压关，或者直接升级成更有实战价值的题。
- L16 不应只是传送门展示。它应该先给 1-2 步安全理解窗口，然后马上用钥匙距离、追击者或门位压力逼玩家把传送门纳入路线。
- L17/L18 不应都是“传送门又来了”。至少一关必须变成真正的小考：不用传送门会明显亏节奏、被贴近，或者错过逃生门。
- 每 3-4 关需要一个小高潮关，像一盘成型残局，而不是连续低压教学。玩家需要“终于用上了”的释放感。
- 主动技能一旦教会，就应该成为玩家后续工具箱的一部分。旋转魔方在 L04 首次出现后，后续关卡默认可用；关卡设计应该通过局面让玩家判断“值不值得拧”，而不是频繁禁用按钮。
- 审查结论：L10 当前与 L04 的解法骨架重复，应作为第一批删改对象。不要保留“换个名字再教一次旋转”的关卡；要么合并，要么改成旋转 + 守钥者/追击压力的真题。
- 审查结论：L18 已从单纯传送门题升级为“旋转 + 传送门 + 敌人也走门”的组合小考。验证标准是：最佳解会使用传送门，不走传送门至少亏 2 拍，且敌人路径也承认传送门。
- 2026-06-09 进一步修正：L09 保留为第一幕无新规则实战；L10 不删除编号，而是重做成“追击者 + 守钥者 + 旋转拆位”的真题。这样既保住剧情/选关索引，又移除重复体验。
- L12 标题改为“出口？”。玩家通关后应该进入漫画式剧情转场，揭示门后不是出口，而是第二幕外壳；L13 之后在 UI 上也应明显区别于第一幕。
- 四阶魔方不能沿用三阶的保守难度。更高阶的意义是给玩家更多空间、更多路线变化和更多容错，然后用更多敌人/组合机制把空间价值逼出来。四阶如果仍只放一个追击者或无怪教学，就会显得空、软、没升级。
- 2026-06-09 剧透修正：第二幕不应在初始选关 UI 直接暴露。默认只显示 L01-L12；L12「出口？」通关后通过漫画式剧情转场解锁 L13 之后的第二幕关卡。
- L12 通关后的胜利弹窗不能写“再接再厉”。这里不是普通过关，而是第一幕结尾和第二幕入口，按钮应明确改成“进入第二幕”。
- 守钥者规则修正：未拿钥匙时它守钥/找钥匙；如果旋转把钥匙转走，它应该优先重新找钥匙。特殊关卡可以设置为拿钥匙后守门，默认仍是拿钥匙后狂暴追人。
- 对话/剧情不是装饰。玩家需要感到主角一直在场，而不是右侧通讯只冒一次泡。后续每章至少要有开场、关键机制首次出现、失败、通关和章节转场的主角反应。

### 主角与剧情模块

2026-06-09 新增 `story.js`，专门负责主角塑造、关系状态、剧情节拍和事件反应。`dialogue.js` 继续作为具体台词库，`main.js` 只调用剧情模块，不再承担人物逻辑。

核心原则：

- 不做指数爆炸的巨型分支树。使用“主线骨架 + 状态变量 + 事件短反应 + 少量关系变化”的混合结构。
- 主角不是功能播报员。她要有稳定的人格：傲娇吐槽、黑色幽默、反工具人、聪明但不全知。
- 玩家仍然主要玩解谜。通讯要少字、常在、能记住玩家的口吻，而不是把右侧平板变成一大段小说。
- 玩家回复保持颜文字和极少按钮。隐藏变量记录稳定、温柔、吐槽三类语气，再影响主角称呼、吐槽强度、信任感和未来小段落。
- 每个章节至少准备：开场反应、新机制反应、拿钥匙反应、失败反应、胜利反应、章节转场反应。
- 每个新道具/技能进入设计时，都要补一条主角视角反应：她怎么看这个东西，它让她更信任玩家还是更怀疑折叠机。
- 每个事件反应都必须服务游戏理解或角色关系。不能为了“有剧情”而塞谜语式台词；玩家看完要更懂局面、更在意主角，至少占一项。

当前 `story.js` 已包含：

- 主角人物圣经：编号 E-7、拒绝编号、真名暂缺、语气支柱、禁忌写法和长期弧线。
- 关系状态：同步语气、羁绊、信任、关心、吐槽默契、玩家回应记忆。
- 场景路由：拿钥匙、守门压力、传送门、第二幕旋转、失败/胜利等事件可以进入不同通讯段落。
- 待机气泡：主角会根据当前关卡、钥匙状态、守卫状态、传送门和玩家语气给不同短句，避免通讯页只有一句固定话。

写作风格底线：

- 少用“你不是最后一步才输的”这种 AI 味复盘句。失败分析要具体指出“哪一回合、哪条线、哪个敌人因此接近”，而不是给玩家讲大道理。
- 第一人称剧情必须让玩家看懂发生了什么。可以怪、可以黑色幽默，但不能用“脚下不是地面”这类让人困惑的空话。
- 主角可以吐槽玩家，但不能让玩家觉得自己被系统骂。她的嘴硬应该服务亲近感，不是降低玩家自尊。

2026-06-09 主角“人味”修正：

- 主角不能像程序播报。真人突然掉进奇幻空间，第一反应应该是不信、慌、嘴硬、自保、质问玩家，而不是清楚地交代规则、身份和操作方式。
- 开场顺序必须从“她醒来并误解现场”开始，然后才发现玩家画线、能看全局、能拧空间。不要一上来就说“你能画路”，那是教程 UI 的口吻。
- 主角台词优先写行动反应，而不是设定解释。设定必须等玩家和她经历过对应事件后再揭露。
- 每次移动、拿钥匙、旋转、传送、敌人贴近、胜利、失败，都至少给右上角主角气泡一个短反应。关键事件可以打开完整通讯段落，普通行动只给 1 句短气泡，避免刷屏。
- 短气泡要像人在现场说话，例如“看见线了。我走。”、“拿到了。现在快走。”、“别突然拧，我差点咬到舌头。”，而不是“路线执行成功”、“钥匙状态更新”。
- 胜利/失败不再只用系统文案。玩家应该感到“我救到了她”或“我刚刚害她被抓了”，这是 IP 情感黏性的核心。

关键物件占位红线：

- 敌人不能站在钥匙、门等关键物件上，开局和移动过程中都不允许。
- 守钥者可以守钥匙旁边、守门旁边、威胁路线，但不能和钥匙/门图标重合。
- 守门者的设计语义是“堵门线”，不是“踩在门上”。它应该停在门相邻格制造压力。
- 验证器必须检查 `enemyOnKey` 和 `enemyOnExit`，一旦为 true 直接失败。

2026-06-09 UI/反馈推进方向：

- 右侧终端四个栏目需要未读提示。通讯、任务、档案有新内容时，在对应 tab 上显示红色数字角标；玩家打开该栏后清除。否则玩家会忘记看通讯和档案。
- 主角在敌人距离变近、贴脸、拿钥匙、旋转、传送、胜利/失败时都应给短气泡或表情反应。她不需要每步长篇说话，但玩家必须感觉她一直在场。
- 档案栏应随关卡持续更新，不只是静态世界观。可以放新机制记录、敌人资料、折叠机线索，也可以放成就，例如最短速通、惊险逃脱、无旋转通关、贴脸逃生。
- 第二幕不应和第一幕挤在同一个选关页里。L13 默认隐藏；L12 之后解锁第二幕时，应进入第二幕分页或第二本残局册，避免剧透，也让章节升级更有仪式感。
- 技能/物品说明不要直接铺文字。例如“旋转消耗 2 AP，旋转会改变钥匙、门和敌人的相对位置；误转可悔棋”应折叠成信息图标 tooltip，鼠标悬停或点击后再显示。
- 第一屏和关卡卡片要继续减少文字。敌人数量用敌人头像/贴图 x2 表示；无敌人不写；可旋转、传送门等机制尽量用图标表达，而且只在首次出现或章节摘要里标一次，减少重复信息和后续英翻工作量。
- 传送门视觉要升级为可识别的发光椭圆裂缝：蓝/橙一对、内侧半透明空间扭曲、边缘流动粒子。但不能精确复刻 Portal 的具体商业外观，应该做成“折叠机裂缝”的自有风格。
- 钥匙模型需要更明显倾斜/竖起，避免像贴在格子上的平面图标。安全出口应保持绿色语义，钥匙保持黄/金色语义。

未来新物品/新技能的教学分级：

1. 一眼懂的公开地形，例如基础传送门、清晰单向箭头：不需要完整教学关，只需要安全首用节拍和视觉提示。
2. 会改变失败原因的规则，例如敌人专用门、延迟门、守门机制：需要安全首用节拍，并在失败复盘里讲清楚。
3. 会改变输入方式的技能，例如玩家主动放置诱饵、扫描、封锁：需要更明确的引导关或短教程，因为玩家要先学会怎么操作。
4. 会改变世界铁律的机制，例如门不随魔方旋转：必须作为特殊事件郑重呈现，否则玩家会觉得系统前后矛盾。

推荐新增物品/技能：

1. 传送门：跨面短捷径，让两个门端互为相邻格。第一版先做固定地形，不做玩家自由放置；门必须公开显示，玩家和敌人都能走。作用是制造 4x4 的局部捷径，但不能泛滥，否则会削弱立方体拓扑。
2. 锚点门：少数关卡中的门不随层旋转，而是固定在外壳上。它能解决“中心关键点被迫绕路”的问题，但必须作为特殊规则明确展示，不能默认改变第一幕铁律。
3. 条件传送门：拿钥匙后开启、关闭或改变方向。适合把“取钥即逃”的压力升级，但必须晚于基础传送门出现。
4. 噪声钥匙：拿到后不会立刻开门，而是暴露一部分敌人隐藏巡逻路线。这个适合第二幕，不适合第一幕。
5. 层锁：某一层暂时不能旋转，需要先经过锁栓格解除。它让“能不能旋转”成为残局条件，而不是增加按钮。
6. 路线回声：上一回合玩家画过的终点会留下回声，有敌人会优先靠近回声。这个可以做高阶敌人，但必须公开规则。

推荐新增敌人：

1. 巡逻者：按固定循环走，不追人。4x4 需要这种可预测障碍，否则全是追击会太压迫。
2. 折叠猎手：只在玩家旋转后行动，逼玩家把旋转也当成风险。
3. 镜像守卫：和主角相对某条轴镜像移动一格，适合 4x4 的空间理解，但要晚一点出现。

第二幕叙事钩子：

- 主角发现某些格子上有旧路线痕迹，说明她不是第一个 E 编号。
- 档案页出现残缺记录：E-1 到 E-6 的结局被折叠机剪掉。
- 玩家和主角的关系从“你带我逃”升级为“我们要搞清楚这个机器为什么需要逃亡数据”。
- 第二幕结尾可以揭示：玩家终端也在被折叠机观察，外侧不一定安全。

### 第一幕正式残局

当前 L01-L08 是教学关，不是完整的第一幕高潮。它们已经能教会规则，但普通玩家会产生“学了半天没处使”的无力感。因此 L09-L12 已作为第一幕正式残局接入，让玩家第一次把已学规则组合起来。

当前结构：

1. L09 正式开跑：双追击者 + 钥匙门 + 无旋转，考路线规划和避开出口侧压力。
2. L10 拧歪牢房：双追击者 + 旋转门，考先拧世界再逃。
3. L11 遛锁：守钥者 + 追击者 + 无旋转，考绕路引诱与撤离。
4. L12 门后还有门：追击者 + 守钥者 + 一次关键旋转，是第一幕毕业考。

L12 难度标准：

- 第一次看有压力。
- 乱走 2 到 3 次会死。
- 认真看威胁线、用一次旋转、必要时悔棋试一次后能过。
- 通关后玩家能复述：“我先把钥匙/门的位置拧开，再引走守钥者，最后冲门。”
- 这不是最终 Boss，而是教程毕业考。目标是让玩家第一次觉得“前面学的终于派上用场”，不是把玩家卡到退出。

当前不建议先加新技能。新技能会稀释“旋转立方体逃亡”这个核心卖点。第一幕收束前，优先做漫画序章、L09-L12、第一幕结尾漫画和通关演出。

当前验证结果：

- L09-L12 均可解。
- L10 和 L12 均必须使用旋转，且无旋转解不存在。
- L11 需要比 L06 更长的绕路和引诱节奏，不再是守钥教学复刻。
- L12 已通过真实 UI 操作通关验证：4 回合、1 次旋转，并正常触发第一幕结尾漫画。

### 当前普通用户巡检结论

当前 demo 的正面状态：

- 第一屏已经能在 1280x720 下完整显示残局册、本局谜面、规则速览和进入按钮。
- 开局已有漫画序章，采用第一人称、傲娇吐槽、黑色幽默。
- L01 的拖线教学清楚，旋转和敌人 UI 会按关卡上下文隐藏。
- L04 已能显示旋转控件、旋转层提示和 XYZ 轴参考。
- L08 已收敛成只教“拿钥匙后守钥者 2 格追击”，不再把旋转和狂暴一起塞给玩家。
- L09-L12 已接入第一幕正式残局，L12 通关后有结尾漫画钩子。
- 关卡验证器显示 L01-L12 都可解，且核心教学/实战目标基本成立。

当前 demo 的关键缺口：

- L10 仍然和 L04 的结构接近，后续可以继续打磨成更独立的旋转实战题。
- 漫画目前还是 UI 分镜，不是正式手绘资产。作为 IP demo 可用，但未来需要真正美术化。
- 旋转控件仍有工程语言残留。可以保留给操作，但漫画和关卡文案要把它翻译成角色视角，例如“我把牢房拧歪了”，而不是只说 X/Y/Z。
- 主角声音已经出现，但还只在序章和结尾。后续章节开场、失败短句、通关短句都应逐步继承这种嘴硬吐槽风格。

## 玩家吸引力

目标玩家喜欢公平、紧张、聪明、可复盘的脑力挑战。

这款游戏满足的需求：

- 智力顿悟：玩家亲手看懂三维局面，并找到生路。
- 可控压力：敌人意图公开，失败来自判断错误，而不是随机惩罚。
- 短局复盘：每关像一盘残局，适合反复挑战最优解。
- 操作参与感：玩家不是让机器自动寻路，而是亲手画出逃亡路径。
- 独特空间感：胜利不只是走到出口，而是把棋盘本身拧成可逃离的形态。
- 低门槛空间辅助：空间感弱的玩家可以靠下一步高亮、跨面提示、规则图鉴和悔棋进入游戏，而不是被展开图和魔方对应关系挡在门外。

## 道具有效性标准

每个道具、技能、敌人和特殊地形在进入主线前，都必须回答三个问题：

1. 如果玩家不用它，局面是否会明显变差，而不是只是少拿一个教学勾选？
2. 如果玩家用了它，是否能产生新的决策，而不是替玩家自动解题？
3. 它是否服务“手动画路、旋转空间、公开敌意图”这三个核心，而不是把游戏拖向传统技能冷却战棋？

合格例子：

- 被砍例子：坐标钉。它能解释，但玩家感受不到“没有它就亏”，因此不配占用第二幕主线工具位。
- 传送门合格的方式不是“门口写着请走门”，而是正常路径会被追捕者压死，传送门提供一条更短但也可能让敌人借用的风险捷径。
- 诱饵信标合格的方式不是“敌人必须吃诱饵”，而是玩家如果不调动敌人，钥匙/门线路会被封死；诱饵只是创造调位机会。

不合格例子：

- 关卡开始弹字“请使用传送门”，但不用也能轻松过。
- 工具只是降低步数评分，不影响真实生死局面。
- 工具一按就自动给出正确路线，玩家只是在执行系统答案。
- 新技能只改变数值，例如多走一格、少等一回合，却没有改变局面结构。

作者验证器可以记录“最佳解是否使用该道具”“无该道具是否可解”“不用该道具会多付出多少回合/风险”，但这些结论只服务设计调试。玩家看到的应该是局面本身在提醒他，而不是系统用作业题口吻命令他。

## 基础传送门设计案

当前“折叠桥/折叠通道”改名为基础传送门。原因：普通玩家对“桥”容易理解成连接线或装饰，而“传送门”能一眼表达“从 A 到 B”。但视觉必须原创，不能复刻《Portal》的蓝/橙椭圆门、比例和火焰边缘；我们使用青色入口 + 金色出口 + 立方体裂环，借通用读法，不借具体 IP。

### 核心规则

- 基础传送门由两个端点组成，两个端点互为相邻格。
- 玩家、追击者、守钥者等会移动的单位都承认这条邻接关系。
- 传送门不是玩家当前可放置技能。主线前中期只做关卡地形，后期再考虑玩家放置版本。
- 传送门不能直接替代立方体跨面移动。它只制造局部捷径，不改变整张棋盘的基础拓扑。
- 门端可以随层旋转移动；如果未来出现“不随旋转”的门，必须作为新类型单独教学。

### 视觉方案

- 平时显示两个强识别端点：A/B、同编号或同符号。不要长期拉一条粗线穿过展开图。
- 玩家 hover 端点、路线经过端点、敌人预告经过端点时，才显示短暂连接线。
- 连接线必须低于路线、钥匙、门、敌人威胁的视觉优先级。
- 如果同关出现多个传送门，必须用符号区分，不能只靠颜色。色觉玩家不能被橙黄蓝绿折磨。
- 失败复盘里若敌人通过传送门接近玩家，必须明确标出“它从 A 端进，从 B 端出”，否则玩家会觉得 AI 瞬移耍赖。

### 关卡节奏

1. 规则展示关：没有敌人或只有远处敌人。目标是让玩家第一次相信“这两个端点互为邻格”。这一关可以简单，但不能长期停留。
2. 价值展示关：普通路看似能走，但会慢一拍；通道提供节奏优势。玩家应感觉“我不是被命令走通道，是自己看出它救了我”。
3. 风险展示关：敌人也能走通道。玩家不能只把它当免费捷径，还要考虑把敌人送近的副作用。
4. 组合小考关：传送门 + 追击压力。传送门负责改变局面，追击者负责制造时间压力；不再加入坐标钉这种弱工具。

### 当前 L16-L17 的犀利检查

- L16「双端传送门」目前是规则展示关。它证明了传送门能被路径系统承认，但没有敌人压力，因此只负责建立读法。
- L17「门边追击」先负责传送门 + 追击压力，不强行证明敌人穿门。
- L18 承担“没有传送门会明显亏节奏，且敌人也会穿门贴近”的小考职责。

### L18 传送门小考目标

L18 的目标不是再教“门是什么”，而是第一次让玩家亲手证明“传送门为什么有用”。当前已改为 L18「传送门小考」。

- 棋盘：4x4。
- 规则量：固定双向传送门 + 一个追击者；不引入守钥者、狂暴、单向门和锚点门。
- 坐标钉：已从主线工具链删除。原因很直接：玩家能理解它，但感觉不到价值；一个能被解释却不能制造局面价值的工具应该砍。
- 局面结构：钥匙和门之间存在一条普通路线，但普通路线比传送门解至少慢 2 回合；传送门提供更短撤离节奏。
- 风险结构：追击者也能通过传送门缩短距离。当前验证器要求追击者在最佳解中实际通过传送门追近玩家。
- 验收句：通关玩家应该能说出“我走普通路会慢，穿门能抢节奏，但敌人也算这条路。”
- 失败复盘：必须能指出敌人是否通过传送门接近，或玩家是否在门端落入威胁。

### 2026-06-09 坐标钉砍掉结论

- 蓝圈/蓝格：下一步可走位置。这个必须稳定、直白，不和任何技能混用。
- 坐标钉：删除玩家可见入口。不是因为无法解释，而是因为解释完仍不够有趣。
- 犀利结论：玩家说“我没感觉到有什么用”时，不要硬教育玩家；这就是弱功能暴露了。
- 后续设计要求：除非坐标钉升级为能改变局面的强工具，例如锁定旋转层、阻断敌人路线或固定门端，否则不要重新放回主线。

这关不应该依靠“请使用传送门”的文字成立。它应该靠红色威胁线和路线长度逼玩家自己看出答案。

### 有效性验收

一个固定折叠通道关卡，至少要满足以下两项：

1. 最佳解或自然解会使用通道。
2. 不使用通道会明显多花回合、进入威胁线、错过钥匙节奏或无法通关。
3. 敌人路径也会承认通道，且玩家能在预告中看出来。
4. 玩家第一次失败后能复述：“我不是死在最后一步，是没算通道带来的距离变化。”

如果一个通道关只是“有桥更快，但没桥也轻松”，它只能做隐藏挑战或低压教学，不能作为第二幕主线新机制。

### 普通玩家不过载标准

- 一个学习节拍只教一种新东西，但不等于每个新东西都要单开一关。首次通道关不要同时教狂暴、锚点门、单向门。
- 右侧平板不能把通道解释成长文。优先用端点闪烁、下一步高亮和失败复盘讲规则。
- 玩家需要知道“敌人也能走”，但不需要一开始知道未来所有传送门类型。
- 如果玩家第二次失败仍然不知道敌人怎么贴近，说明不是玩家笨，是通道预告和复盘没做好。

### 可持续扩展

基础传送门稳定后，传送门家族可以按以下顺序扩展：

1. 单向通道：只允许 A 到 B，不允许 B 到 A。适合制造撤离路线，但必须用箭头符号强提示。
2. 钥匙通道：拿钥匙后开启或关闭。适合把“取钥即逃”的压力升级，但要避免又变成门禁刷卡。
3. 敌人专用通道：只让敌人用。风险很高，容易让玩家觉得不公平，必须晚期出现并强视觉提示。
4. 延迟通道：进入后下一回合出现。适合高阶残局，不适合第二幕开局。
5. 玩家放置通道：强度最大，容易篡位成另一个游戏。只适合后期高阶技能、挑战模式或少数特殊章节。

扩展顺序的原则是：先固定、双向、公开，再逐步引入方向、条件、阵营和延迟。不能一口气把传送门家族全倒进第二幕。

## 独特性

外部表达不要强调“传统魔方游戏”。传统魔方预期会把玩家引向还原、速拧和颜色排列。

本项目的独特性应表达为：

- 立方体不是被解决的物件，而是战场本身。
- 玩家不是还原立方体，而是利用立方体逃生。
- 这是可旋转空间上的战术残局，而不是普通立方体解谜或平面战棋。
- 现阶段不追求用新输入模式扩大受众。真正差异仍然来自“在可旋转立方体上手工规划逃亡残局”，辅助设计必须服务这个核心。
- 和规则改写类解谜的区别：本项目不让玩家改写句子或规则，而是在稳定公开规则下规划路线、旋转空间、调动敌人。
- 和递归空间类解谜的区别：本项目的爽点不是“空间套空间”的概念惊奇，而是短局战术推演、敌人压力和可复盘逃亡。
- 和传统回合战术的区别：本项目没有职业队伍和技能轮换，核心单位只有一个逃脱者，玩家的主要动词是画路、旋转、标记和改造战场。

- 随机生成和 roguelite 暂缓。
- 多芯片收集暂缓。
- 多 AI 自由配置暂缓。
- 复杂技能树、装备、成长系统暂缓。

4. 棋子 IP 化第一版：采用“3D 棋座 + 清晰徽章 + 少量动画”，让逃脱者、追捕者、守钥者从功能棋子开始长出角色符号。

8. 旋转教学继续打磨：旋转关必须强制旋转，并加入醒目的 XYZ 坐标轴/方向锚点；2D 只做影响范围轻提示，不完整剧透结果。
9. 守钥者规则固化与继续验证：取钥前同面引诱 1 格，取钥后狂暴追击 2 格；默认不守门，守门只作为未来高阶特殊机制。
10. 悔棋历史栈扩展为复盘系统：显示上一手、失败原因、被谁抓住。
11. 章节漫画继续扩展：后续章节开头和结尾都用同一套第一人称吐槽语气，但仍保持短、直接、少字。
12. 暂缓复杂技能、长剧情和高成本角色模型。它们会扩大规则和制作负担；当前 IP demo 最缺的是让普通玩家稳定看懂、记住角色、记住“旋转世界逃亡”这个核心场面。
13. 暂缓镜头相对方向键，除非后续外部试玩证明现有读图辅助仍然不够。
14. 为每个新道具建立“局面价值验证”：不用它是否会导致路线变长、风险增加、敌人压近或无法通关；如果答案是否定的，就不要把它包装成主线新机制。
15. L18「传送门小考」已接入，下一步应在真实试玩中观察：玩家是否能自然看出传送门节奏优势，是否能理解追击者也通过传送门贴近，而不是误以为 AI 瞬移。

## 2026-06-09 右侧平板与信息减负决策

本轮确认：右侧终端不是普通 UI 面板，而是游戏 IP 的“平板终端”。它应该承载三类价值：玩家规划路线、主角存在感、世界记录。玩家会把注意力长期放在 3D 魔方和展开图上，所以平板其他栏目必须像社交软件一样有未读红点，提醒新通讯、新任务状态和新档案。

- 展开图仍是主棋盘。通讯、任务、档案都是可召出的模块，不能抢展开图主地位。
- 通讯 tab 有新消息时显示红色数字；玩家打开通讯后清零。
- 档案 tab 有新碎片或成就时显示红色数字；玩家打开档案后清零。
- 任务 tab 在钥匙状态、失败、胜利等关键事件后提醒玩家，但不要每帧刷红点。
- 主角在敌人贴近时要有短句或表情反应，例如“近了。非常近。”这种短促反馈。重点不是解释“你在攻击范围内”，而是帮玩家意识到“敌人是怎样一步步贴近的”。

### 选关防剧透

L12「出口？」之后才进入第二幕。第二幕不能直接排在第一幕同一页，否则玩家在通关前就知道“门后还有新东西”，削弱剧情节拍。

- 第一幕只显示 L01-L12。
- L13 以后放在第二幕独立页。
- 第二幕页签只有在 L12 结尾解锁后出现。
- L12 通关弹窗必须进入漫画/剧情节拍，而不是普通“再接再厉”感。

### 关卡信息图标化

残局册要像棋谱，不像说明书。关卡卡片尽量少用文字，避免玩家扫卡片时被重复信息淹没，也减少后续英文翻译成本。

- 敌人数量用敌人符号 x2 表示；没有敌人就不写。
- 可旋转、传送门等机制用图标表达，而且只在首次出现或章节摘要中标一次，后续默认玩家已经知道。
- 长说明收进 `!` tooltip。老手不被文字打断，新手可以查。
- 关卡概念文案留在选中后的谜面区，不塞进每张卡。

### 档案与成就

档案不是背景设定倾倒口，而是“玩家刚刚经历的事被世界记录”。它应该持续更新，但不能强迫阅读。

- 档案碎片：折叠机、E-7、外侧的人、守钥者、空间折叠、第二层外壳、传送裂缝等，随关卡或事件解锁。
- 成就记录：第一次逃脱、惊险逃脱、最短速通、门后不是门、折叠捷径等，作为轻量长期目标。
- 成就不应破坏残局纯度。它们是回放价值和玩家炫耀点，不是强制任务。

### 道具视觉与版权边界

传送门需要一眼像“门”，但不能精确复刻《Portal》的商业外观。当前方向是蓝/橙一对的发光竖椭圆裂缝，使用折叠机自己的线路、裂环和空间扭曲语言。

- 可以借用“蓝/橙双端传送”的通用读法。
- 不照搬具体比例、边缘火焰形状、机械结构和 IP 标识。
- 钥匙应保持钥匙形，且要倾斜/抬高，避免像平贴在格子上的图标。
- 安全出口在拿钥匙后应转为绿色，未解锁状态可以保留警戒色。

### 本轮犀利结论

当前 demo 不缺“更多设定”，缺的是每个新信息都有正确的出现位置。剧情应该放在通讯和章节漫画里；玩法信息应该放在图标、tooltip、红点和失败复盘里；道具价值应该由局面证明，而不是靠文案解释。继续推进时不要再为了“教一个新东西”单独做一关，除非这关同时能制造一个值得玩的压力局面。

## 2026-06-09 E-7、标题与手机 UI 决策

当前暂定游戏名：

- 中文名：黎明魔方
- 英文名：E-7: Cube Pursuit 或 E-7: Escape from Cubes 继续比较；中文已先锁定“黎明魔方”方向。

标题判断：

- “E-7”是角色 IP，“魔方/立方追逃”是玩法 IP。标题必须同时让玩家感到有人物和立方空间玩法。
- “黎明魔方”比“折叠黎明”更贴近玩法第一眼：玩家能想到魔方、空间和逃亡，而不是纯文艺叙事。
- 后续标题演出可在第一幕结束后用巨大的各种魔方堆叠出游戏名，作为“门后不是出口”的震撼揭示。

### E-7 的真实反应规则

E-7 是 18 岁左右的人类女孩，从 Falling IP 接入：她陷入床/被床吞入折叠空间，来到这里。她的目标不是“通关”，而是回家。回家无需额外动机；任何正常人掉入这种环境都会想回家。

她的性格方向：

- 害怕，但坚强。
- 嘴硬，用毒舌和调侃掩饰不安。
- 不会无条件信任外部引导者。
- 她面对未知“玩家/终端”时会质疑、反抗、犹豫、试探，而不是立刻听话。
- 她不是系统教程播报员，不能替规则念说明书。

开场需要从“系统接入”改成“人类受惊”：

- 她先被震惊、沉默、确认现实。
- 她会问“你是谁”“你为什么能看见我”“我凭什么跟你走”。
- 玩家需要通过第一次画路建立最低限度信任。
- 早期通讯重点是“互相确认”而不是“解释世界观”。

更像真人的关键句式：

- “……”
- “等一下。”
- “你是谁？”
- “你能看见我？”
- “我为什么要跟着你画的线走？”
- “我们……还是没有逃出来？”

### 右侧手机 UI 方向

右侧终端应从“平板/控制台”升级为“手机”。理由：

- E-7 也有手机，玩家和 E-7 通过手机联络，叙事更自然。
- 手机是现代玩家熟悉的社交界面，未读红点、聊天、任务、档案都更容易理解。
- 主角 IP 可以通过手机里的表情、气泡、信号、震动、头像/立绘位持续存在。

手机模块建议：

- 聊天：E-7 的常驻存在、表情、短句、剧情推进。
- 展开图：路线规划主棋盘。
- 任务：钥匙、出口、当前危险状态。
- 档案：世界碎片和成就。
- 控制：执行路线、跳过回合、空间折叠等主操作。

### 左侧面板精简方向

左侧不应继续承担大量操作。它可以退化为极简 HUD：

- 当前关卡名/目标。
- 回合/AP。
- 少量状态提示。

可以迁移到右侧手机的内容：

- 钥匙/出口状态。
- 执行路线。
- 跳过回合。
- 空间折叠。

保留在左上/顶部的元操作：

- 悔棋。
- 重置本局。
- 回到主菜单。

原因：这些操作带有元游戏性质，不应该和 E-7 手机里的“真实行动”混在一起。把它们放在左上角，可以减少代入感破坏。

### 空间折叠控件重做

空间折叠最多两行，不再是一整块说明区：

1. 第一行：空间折叠。
2. 第二行：轴向、层数、方向。

方向应使用弧形箭头图标表示顺时针/逆时针，而不是文字按钮。左下角静态 XYZ 参考目前像不动贴图，容易让玩家觉得“它没有功能”；后续应改为：

- 方向箭头直接嵌入折叠控件。
- 当前轴向/层数在魔方上有强高亮。
- 若保留轴参考，必须随当前轴和方向动态变化；否则移除。

### 本轮 UI 犀利结论

当前左右面板像开发调试 UI，不像 E-7 和玩家共同使用的逃亡工具。下一次大 UI 迭代应把右侧做成手机，把真实行动塞进手机，把元操作移到左上角，把左侧压缩成极简状态栏。这样玩法更沉浸，主角 IP 更容易成立，也更符合“带 E-7 回家”的叙事。

## 2026-06-09 手机 UI 与 E-7 开场已落地

本轮实现目标：把“黎明魔方”从开发面板感推进到“玩家通过手机带 E-7 回家”的形态。

### 已落地

- 游戏中文名落到 UI：黎明魔方。
- 开场漫画改为 E-7 从床上坠入折叠空间后的第一人称反应：震惊、质疑玩家、拒绝盲从、但想回家。
- E-7 设定更新为 18 岁左右、害怕但强撑、靠毒舌掩饰不安；她不是教程播报员。
- 右侧改成 E-7 手机：上方保留通讯气泡和立绘空位；模块为展开图、通讯、任务、档案；执行路线、跳过回合、空间折叠都放入手机。
- 左侧压缩为极简 HUD：当前任务、回合、AP、少量路线提示。
- 悔棋、重置、本局返回残局册移到左上角，和真实世界内操作分离。
- 空间折叠控件压缩为两行：标题/消耗/提示，以及轴向/层数/弧形方向箭头。
- 删除左下角静态 XYZ 贴图。它没有跟随当前操作动态变化，只会制造“看起来像功能但什么也不做”的困惑。
- 按钮与资源版本号更新，避免浏览器缓存造成假 bug。

### 设计检查

从普通玩家视角：新版界面的第一眼更像“我正在和 E-7 通讯并救她”，不是在操作一个抽象调试器。左侧只保留生存信息，右侧手机承担路线、聊天和行动，注意力路径更清楚。

从游戏设计师视角：这个改法强化了双 IP：

- 玩法 IP：魔方空间、路线规划、空间折叠、追逃残局。
- 角色 IP：E-7 通过手机持续存在，玩家不是单纯控制棋子，而是在和一个嘴硬但害怕的人合作。

### 仍需盯紧

- 关卡校验显示全部可解，且没有敌人重叠钥匙/门。
- 但第二幕部分关卡仍存在“旋转可用但不一定必要”的问题。后续调谜题时要继续坚持：道具/技能不是规则强迫玩家用，而是局势逼玩家主动想到它。
- E-7 台词已经比系统日志更像人，但还没到“真正有灵魂”。下一轮剧情应把“害怕、试探、嘴硬、想回家”写进每个关键事件，而不是只写在开头。

## 2026-06-09 第二幕后半：缺角/缺面与新工具方向

本轮确认：可以开始从新的技能、道具和破损魔方结构继续推进。这里的核心不是“加更多按钮”，而是让四阶魔方真的变成第二幕：空间更大、局面更松，但地形和工具组合更复杂。

### 犀利判断

缺角、缺面是非常适合本项目的机制，因为它只属于“魔方追逃”这个题材，别人很难直接拿去套传统迷宫。它能强化三个卖点：

- 魔方不是棋盘皮肤，而是一个会坏、会折叠、会学习的空间实体。
- 玩家不能只背最短路，要开始判断“这块地还在不在”“旋转后缺口会去哪”。
- E-7 的存在感会更强：脚下不是抽象格子，而是真的会塌、会断、会让她害怕。

但必须克制。缺面如果太早、太大，会直接变成“我看不懂哪里能走”，尤其对普通玩家很不友好。所以引入顺序必须从小到大：

1. 缺格：少量单格虚空，不能站、不能走。
2. 缺角：一个角落的多个表面格一起消失，形成明显三维缺口。
3. 破边：一条边附近断开，影响跨面路线。
4. 缺面：整块面或大区域缺失，只能作为章节高潮或特殊关，不适合频繁使用。

### 破损魔方规则

第一版建议叫“虚空缺口”或“断面”，不要叫陷阱。它不是敌对单位，而是世界结构。

- 虚空格不能被玩家、敌人、钥匙、门、传送门端点占用。
- 画路线时不能穿过虚空格，除非玩家拥有对应工具。
- 虚空格随层旋转移动。理由：它是魔方结构的一部分，不是屏幕贴图。
- 展开图上必须用高对比黑色裂纹/断边表示，不能只靠深色填充。
- 3D 魔方上缺口必须真的“空掉”，让玩家第一眼觉得这个世界被咬掉了一块。

普通玩家理解句：黑洞洞的格子不能走；拧魔方时，洞也会跟着转。

### 新工具优先级

#### 1. 临时补片

定位：第一批和缺面配套的新道具。

规则草案：

- E-7 可以携带 1 个补片。
- 玩家可以直接在 3D 魔方或展开图上点击相邻虚空格使用补片；不用把它藏在菜单里。
- 补片只能让 E-7 走一次。她踩过去后，补片立刻碎掉。
- 补片可以用来切断追击节奏：E-7 过得去，追捕者默认不能跟着踩同一块已经碎掉的补片。
- 敌人默认不能使用玩家补片，除非后期出现“学习型敌人”。

为什么它有用：

- 不用补片时，路线会绕远、被追击者贴近，或者拿钥匙后逃不出去。
- 它不需要新增复杂按钮，仍然服务“手动画路线”。
- 它让缺面不是单纯阻碍，而是变成“我要不要把唯一补片用在这里”的残局判断。
- 它还能制造很爽的逃脱瞬间：E-7 过洞，补片碎掉，追捕者被断在身后。

E-7 反应方向：

- “你要我踩这个临时贴片？它最好不是贴纸。”
- “好吧，过来了。下次请提前告诉我地板是试用版。”

#### 2. 诱饵信标

定位：第二批主动工具，用来处理守钥者和多追击压力。

规则草案：

- 信标是场上可拾取的一次性道具，不建议先做成无限技能。
- 使用后可以放到任意可见合法格。玩家可以直接在 3D 魔方或展开图上点选放置位置。
- 下一次敌人行动时，最近的追击者/守钥者优先向信标靠近。
- 信标只影响 1 回合或 2 回合，之后熄灭。
- 守钥者在钥匙未取前可以被信标短暂骗走；钥匙取走后狂暴，信标效果减弱或失效。

为什么它有用：

- 它能让玩家主动制造“引诱”，而不是只被动绕路。
- 它和你之前强调的“引诱守钥者”高度一致。
- 它可以用来证明四阶空间的价值：空间大了，诱饵才有可操作余地。

风险：

- 自由放置是对的，因为诱饵的本质就是“远程调度敌人”。但它必须是一次性/少量资源，并且敌人只会被合理诱导，不会无脑穿越全图。
- 如果解释太多，会变成技能教学课。

第一版限制建议：

- 每关只给 1 个信标。
- 信标只能放在当前展开图可见的合法地面，不能放虚空、钥匙、门、传送门端点或敌人脚下。
- 敌人会向信标靠近，但仍遵守移动规则、虚空、传送门和 AP；不会瞬移。
- 如果 E-7 已经拿到钥匙，守钥者狂暴后只吃一次弱诱导，不能被无限风筝。

E-7 反应方向：

- “把它骗走？好，这个计划听起来终于有点不像送死。”
- “它真过去了。很好，我单方面宣布我们比它聪明三秒。”

#### 3. 单向传送门

定位：传送门家族第二阶段。

规则草案：

- 只允许 A 到 B，不允许 B 到 A。
- 敌人是否能使用由关卡明确视觉标记决定。
- 用箭头和不同门环动画表达方向，不能靠文字。

为什么它有用：

- 它能制造“玩家能逃，敌人不能追”或“玩家逃了但不能回头”的压力。
- 它是基础传送门的自然升级，因为玩家已经知道“门会把 A 和 B 连接起来”，单向门只是在这个已学会的读法上增加方向性。
- 它的核心用途不是“更高级所以更酷”，而是制造不可逆决策：走进去就省路，但不能从原路回来；敌人可能追不过来，也可能在另一侧等你。

不建议和缺面同关首发。两个新读法叠在一起，新手会炸。

#### 4. 外壳锚点

定位：后期特殊规则，不是第二幕马上要做的主工具。

规则草案：

- 被锚定的门、钥匙、传送门端点或缺口不随层旋转。
- 它代表“外壳”而不是“魔方块”，用于剧情上证明折叠机有更高层结构。

为什么现在不急：

- 它会改变第一幕已经建立的铁律：所有东西随层旋转。
- 如果太早出现，玩家会觉得规则不统一。

适合用在章节结尾或第三幕开头。

### 暂时不建议做

- 玩家自由放置传送门：太强，容易把游戏变成另一个传送门解谜，而不是魔方追逃。
- 大范围缺整面：视觉很震撼，但太容易让普通玩家迷路。先做缺格和缺角。
- 多个主动技能栏：会把游戏拖向战棋技能轮换，稀释“画路线 + 拧空间”的核心。
- 永久铺路/永久修复：会削弱缺面的存在感。补片应该短命、珍贵。

### 推荐 L19-L24 原型节奏

L19「少了一格」：首次出现单格虚空。目标只是让玩家知道黑色缺口不能走，仍然有追击压力，但不加新工具。

L20「洞也会转」：虚空格随层旋转。玩家需要先拧层，让缺口离开关键路线，或者让缺口挡住敌人节奏。

L21「临时补片」：补片首次出现。不用补片会绕远并被贴近；用补片能抢回一拍。

L22「断角钥匙」：缺角 + 守钥者。玩家需要利用缺角限制守钥者路线，再拿钥匙。

L23「诱饵信标」：信标首次出现。守钥者不站钥匙，但守住钥匙线；玩家用信标把它骗离关键通道。

L24「破面小考」：缺角 + 补片 + 传送门或旋转，只选两个组合，不要把所有机制全塞进去。目标是让玩家产生“我不是在学规则，我是在下残棋”的感觉。

### 强工具与敌人升级

本轮确认：临时补片、诱饵信标、单向传送门都比早期工具更强，不能继续配第一幕那种轻量敌人密度。否则玩家会觉得关卡被道具碾过去，第二幕没有升级感。

但敌人升级不能只是“多塞几个追击者”。正确做法是让敌人压力专门咬住新工具的副作用：

- 临时补片很强，因为 E-7 过洞后补片碎，追捕者会被断在身后。因此补片关可以增加身后追击者、侧翼追击者，逼玩家判断“补片用来逃命，还是用来抢钥匙线”。
- 诱饵信标很强，因为它能远程调度敌人。因此诱饵关可以增加守钥者 + 追击者组合，甚至两个守不同线路的敌人，逼玩家决定骗谁，而不是一次诱饵解决全局。
- 单向传送门很强，因为它制造不可逆捷径。因此单向门关可以增加门后伏击者、门前追击者或守门压力，逼玩家判断“现在进门是不是把自己送进死角”。

敌人数量建议：

- L19-L20：1-2 个敌人即可。缺口刚出现，重点是读懂“地不见了”和“洞会转”。
- L21 补片首关：至少 2 个敌人，最好一个身后追击、一个侧边压线，让补片碎裂产生真实逃脱价值。
- L22 缺角 + 守钥者：1 个守钥者 + 1 个追击者。缺角负责限制路线，追击者负责制造时间压力。
- L23 诱饵首关：1 个守钥者 + 2 个追击者，或 2 个守关键线的敌人。玩家必须用诱饵调动其中一个，另一个仍然制造压力。
- L24 小考：2-3 个敌人上限。超过 3 个时，新机制会被噪音淹没，玩家只会觉得乱。

平衡底线：

- 新工具强，所以可以加敌人；但每关仍必须能让玩家看出“我是因为用了这个工具才赢”，而不是“我靠运气躲过一堆敌人”。
- 敌人增加后，展开图的威胁可视化必须更清楚。否则普通玩家看不懂死因，会以为 AI 耍赖。
- 第二幕允许更难，但不能把每一步都压成唯一解。四阶魔方的价值是更多空间、更多容错和更多策略选择，不是把玩家逼成背答案。

### 设计底线

每个新工具进入主线前必须用验证器或人工复盘回答：

- 不用它是否会路线变长、风险增加、敌人贴近或直接无解？
- 它是否服务手动画路线、旋转空间和敌人意图判断？
- E-7 是否能用一句人话表达它的危险或价值？

如果三个问题答不上来，就先不要实装进主线。

### 对普通玩家的判断

第二幕现在比“只是 4x4”更像第二幕了：玩家会遇到更大的空间、会坏掉的地面、一次性补片、诱饵调度和多传送门选择。它吸引人的点不是数值更高，而是玩家会产生“我刚用一个很聪明的工具活下来”的记忆点。

但仍要警惕两件事：

- 诱饵是最容易让玩家误解的工具。它如果不明显改变敌人目标，玩家会觉得自己按了一个没反馈的按钮。
- 破面和传送门同时出现时，展开图必须足够清楚。否则失败会被玩家理解成“我没看懂地图”，而不是“我判断错了路线”。
